## 2. 各数据源格式详解

### 2.1 all.json (WFCD/warframe-drop-data)

**核心结构**:
```json
{
  "relics": {
    "<relic_name>": {
      "tier": "Lith",
      "relicName": "Lith C14",
      "isVaulted": false,
      "state": "Intact",
      "rewards": [
        { "name": "<item_name>", "rarity": "Common", "chance": 0.5 }
      ]
    }
  },
  "missionRewards": {
    "<node_name>": {
      "rewards": [...]
    }
  },
  "bountyRewards": { ... },
  "keyRewards": { ... },
  "sortieRewards": { ... },
  "conclaveRewards": { ... },
  "syndicateRewards": { ... },
  "cetusBountyRewards": { ... },
  "solarisBountyRewards": { ... },
  "deimosRewards": { ... },
  "zarimanRewards": { ... }
}
```

**关键字段**:
- `relics`: 遗物定义和掉落奖励
- `missionRewards/bountyRewards/keyRewards`: 各类任务奖励
- `isVaulted`: 是否入库（true=入库，false=出库）
- `tier`: 遗物纪元（Lith/Meso/Neo/Axi/Requiem/Vanguard）
- `rarity`: Common/Uncommon/Rare
- `chance`: 掉落概率

---

### 2.2 i18n.json (WFCD/warframe-drop-data)

**核心结构**:
```json
{
  "/Lotus/Types/Game/Projections/T1VoidProjection": {
    "zh": { "name": "Lith Relic", "description": "..." },
    "en": { "name": "Lith Relic", "description": "..." }
  },
  "/Lotus/Language/Missions/MissionName_Crossfire": {
    "zh": "交火",
    "en": "Crossfire"
  }
}
```

**两种格式**:
1. **物品类型** (`/Lotus/Types/...`): 包含 name 和 description
2. **语言条目** (`/Lotus/Language/...`): 直接是翻译字符串

⚠️ **重要注意**: `/Lotus/Types/...` 格式不应作为翻译条目使用！

---

### 2.3 all_items.json (WFCD/warframe-items)

**核心结构**:
```json
{
  "<uniqueName>": {
    "name": "<display_name>",
    "type": "<item_type>",
    "category": "<category>",
    "description": "<description>",
    "rarity": "Common|Uncommon|Rare|Legendary",
    "tradable": true|false,
    "masteryReq": 0,
    "components": [...],
    "patchlogs": [...]
  }
}
```

**关键字段**:
- `uniqueName`: 游戏内唯一标识（如 `/Lotus/Items/Weapons/Pistol/...`）
- `name`: 显示名称（英文）
- `category`: 物品大类（Warframes, Primary, Secondary, Melee, Relics, Mods...）
- `type`: 物品子类型
- `tradable`: 是否可交易
- `masteryReq`: 段位要求
- `rarity`: 稀有度

---

### 2.4 zh_en_dict.json (自定义中英对照词典)

**核心结构**:
```json
{
  "<en_name>": "<zh_name>",
  "Ash Prime Chassis Blueprint": "灰烬 Prime 机体 蓝图",
  "Orokin Cell": "奥罗金电池",
  "Forma": "塑形块"
}
```

**特点**:
- 简单的键值对结构
- 包含 ~17,000 条记录
- 包含 382 条 Blueprint 部件翻译
- 主数据源，优先级最高

---

### 2.5 dict.en.json / dict.zh.json (public-export-plus)

**核心结构**:
```json
{
  "/Lotus/Language/Missions/MissionName_Crossfire": "Crossfire",
  "/Lotus/Language/Items/ItemName_BrutalToroid": "Brutal Toroid",
  "/Lotus/Language/Relics/VoidProjectionName": "|ERA| |CATEGORY| Relic"
}
```

**特点**:
- 基于 DE 官方 Public Export
- key 格式统一为 `/Lotus/Language/...`
- 包含模板变量（如 `|ERA|`, `|COLOR|`）
- 约 35,000 条记录

## 3. 数据内容分析

### 3.1 数据覆盖范围

| 数据类别 | 覆盖源 | 质量评估 |
|----------|--------|----------|
| 遗物掉落 | all.json | 完整 ✅ |
| 物品基础属性 | all_items.json | 完整 ✅ |
| 中英对照 | zh_en_dict.json | 高覆盖 ✅ |
| 游戏术语翻译 | dict.en/dict.zh | 官方级 ✅ |
| 物品多语言 | i18n.json | 补充级 ⚠️ |

### 3.2 数据冗余与冲突

**问题识别**:
1. **i18n.json 混入非翻译数据**: `/Lotus/Types/...` 格式是物品数据，不应进入翻译库
2. **翻译重复**: 同一翻译可能存在于多个数据源
3. **格式不一致**: 不同数据源的 key 格式差异大

**解决方案**:
- 过滤 `/Lotus/Types/...` 格式的 key
- 设定明确的数据源优先级
- 统一 key 格式标准

### 4.3 最优表结构设计

#### 4.3.1 relics.db

```sql
CREATE TABLE relics (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL UNIQUE,   -- "古纪 C7"
    era         TEXT NOT NULL,          -- "古纪"
    code        TEXT NOT NULL,          -- "C7"
    vaulted     INTEGER NOT NULL DEFAULT 0  -- 0=入库,1=出库,2=虚空商人
);

CREATE TABLE relic_parts (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    relic_id    INTEGER NOT NULL,
    part_name   TEXT NOT NULL,         -- 英文名
    rarity      TEXT NOT NULL,         -- Common/Uncommon/Rare
    chance      REAL NOT NULL DEFAULT 0,
    FOREIGN KEY (relic_id) REFERENCES relics(id) ON DELETE CASCADE
);

CREATE TABLE relic_aliases (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    relic_id    INTEGER NOT NULL,
    alias       TEXT NOT NULL UNIQUE,   -- 别名变体
    FOREIGN KEY (relic_id) REFERENCES relics(id) ON DELETE CASCADE
);

CREATE INDEX idx_relic_parts_relic_id ON relic_parts(relic_id);
CREATE INDEX idx_aliases_alias ON relic_aliases(alias);
```

#### 4.3.2 items_i18n.db

CREATE TABLE items (

### 5.4 高级转换逻辑

#### 5.4.1 别名生成逻辑

```python
def generate_aliases(relic_name: str) -> list[str]:
    """为遗物生成多个别名变体"""
    aliases = []
    
    # 原始名
    aliases.append(relic_name)
    
    # 去除空格
    aliases.append(relic_name.replace(" ", ""))
    
    # 全小写带空格
    aliases.append(relic_name.lower())
    
    # 全小写无空格
    aliases.append(relic_name.lower().replace(" ", ""))
    
    # OCR容错变体（数字/字母混淆）
    ocr_map = {'O': '0', 'I': '1', 'L': '1', 'S': '5', 'B': '8'}
    for orig, repl in ocr_map.items():
        aliases.append(relic_name.replace(orig, repl))
        aliases.append(relic_name.replace(orig, repl).lower())
    
    return list(set(aliases))
```

#### 5.4.2 物品名称推导逻辑

```python
def derive_zh_from_pattern(en_name: str, zh_dict: dict) -> str:
    """从模式推导中文翻译"""
    
    # 尝试直接查找
    if en_name in zh_dict:
        return zh_dict[en_name]
    
    # 尝试去掉 Prime 后缀
    if en_name.endswith(" Prime"):
        base_name = en_name[:-6]
        if f"{base_name} Prime" in zh_dict:
            zh = zh_dict[f"{base_name} Prime"]
            # 尝试去除 "Prime" 对应的中文
            for suffix in ["Prime", " Prime"]:
                if zh.endswith("Prime"):
                    return zh[:-5]
                if " Prime" in zh:
                    return zh.replace(" Prime", "")
    
    # 尝试部件名称推导
    part_keywords = ["Chassis", "Neuroptics", "Systems", "Barrel", "Receiver", "Stock", "Blade", "Handle"]
    for part in part_keywords:
        if part in en_name:
            base = en_name.replace(f" {part}", "")
            if base in zh_dict:
                base_zh = zh_dict[base]
                part_zh = {"Chassis": "机体", "Neuroptics": "神经光元", "Systems": "系统"}.get(part, part)
                return f"{base_zh} {part_zh}"
    
    # 返回原始英文名
    return en_name
```

#### 5.4.3 拼音索引生成

```python
from pypinyin import pinyin, Style

def generate_pinyin(zh_name: str) -> str:
    """生成拼音索引（全拼 + 首字母）"""
    # 全拼（空格分隔）
    full_pinyin = " ".join([p[0] for p in pinyin(zh_name, style=Style.NORMAL)])
    
    # 首字母
    initials = "".join([p[0][0] for p in pinyin(zh_name, style=Style.NORMAL)])
    
    return f"{full_pinyin} {initials}"
```
