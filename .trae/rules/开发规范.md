## 1. 项目概况

- **类型**: PySide6 桌面应用(Warframe 遗物辅助工具)
- **入口(新)**: `core/app_shell.py` · **入口(旧)**: `main.py`(只读)
- **开发启动**: `python dev.py --once`(单次运行,不监听)· 默认 watch 模式改 .py 自动重启
- **打包**: `python build.py --zip` → `dist/WARFRAME-RELIC_win64_日期.zip`(详见 §9)
- **核心目录**: `core/`(tokens/services/recognizers/widgets/pages/state + paths.py + immersive_controller.py)
- **设计风格**: Cyberpunk Chamfered(切角+外发光)
- **当前阶段**: UI 重构完成,EXE 打包分发(P1-P3 已验证,详见 `.trae/documents/打包EXE方案.md`)

**铁律**: 新代码用 PySide6,旧代码用 PyQt6,两者绝不混用。

| PyQt6(旧) | → | PySide6(新) |
|---|---|---|
| `from PyQt6.QtWidgets` | → | `from PySide6.QtWidgets` |
| `pyqtSignal(...)` | → | `Signal(...)` |
| `pyqtSlot(...)` | → | `Slot(...)` |

## 4. 颜色/尺寸规范

**颜色必须用 Token**:
```python
# ✅
bg = self.token("bg.raised")
# ❌ 硬编码
bg = "#0E0E24"
```

**尺寸必须是 4 的倍数,用 Space Token**:
```python
# ✅
h = self.space("height.btn_md")  # 36
# ❌
self.setFixedHeight(26)          # 26 不是 4 倍数
```

**样式:继承原生 + 最小自绘**:
```python
# ✅
class CyberButton(CyberWidgetMixin, QPushButton):
    def paintEvent(self, e):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)
        self._draw_chamfered_bg(p)  # 只画 QSS 做不到的
        super().paintEvent(e)        # 文字/点击/禁用 Qt 接管
# ❌
class MyBtn(QWidget):
    def paintEvent(self, e):
        p.drawText(...)  # Qt 已经在做这事
```

| 组件 | 继承 | 自绘 | Qt 自动提供 |
|---|---|---|---|
| 按钮 | QPushButton | 切角+发光 | 点击/文字/快捷键 |
| 输入框 | QLineEdit | 切角边框 | 光标/选中/IME |
| 开关 | QCheckBox | 切角滑块 | 状态/动画 |
| 卡片 | QFrame | 切角+装饰 | 布局 |
| 下拉 | QComboBox | 切角外框 | 弹窗/搜索 |

## 5. 多重继承关键点(Mixin 必读)

**5.1 `__init__` 显式调用基类**(不用 super):
```python
class CyberButton(CyberWidgetMixin, QPushButton):
    def __init__(self, text="", parent=None):
        QPushButton.__init__(self, text, parent)  # 显式,不 super
```

**5.2 事件处理必须 super()**:
| 忘 super | 后果 |
|---|---|
| `mousePressEvent` | clicked 不发射 |
| `paintEvent` | 文字不显示 |
| `keyPressEvent` | 快捷键失效 |

**5.3 paintEvent 顺序固定**:`QPainter → 自绘背景 → super()`(顺序反了会出怪事)

**5.4 Mixin 私有属性加 `_cyber_` 前缀**(避免与 Qt 内部同名)。

## 6. 各层核心规范(文件头模板直接使用)

### 6.1 `core/tokens/` —— L-Infrastructure 基础设施层

```python
"""
[L-Infrastructure] {Name} — Token 解析/缓存

依赖: Python 标准库 + PyYAML
禁止: PySide6, QtWidgets, QtCore
职责: 颜色/尺寸 Token 的解析、缓存、对外提供 API
"""
```

**核心规则**:
- 纯数据层,**模块顶层禁止 import PySide6** —— 保证无 Qt 的进程(单元测试/构建脚本)
  也能导入 Token 体系
- **唯一例外**:`TokenManager.get_qcolor()` 在函数内惰性导入 `QColor`
  (全项目仅此一处 Qt 触点,不得扩散)
- 函数返回 `str`/`int`/`dict`;`QColor` 只经 `get_qcolor()` 返回
- 该不变量由 `tests/test_layer_rules.py` 自动守卫,不靠自觉
- 不读 UI,不持有 widget 引用
- Token 路径格式: `{类别}.{名称}` (`bg.raised`, `height.btn_md`)

### 6.2 `core/services/` —— L-Service 纯业务逻辑层

```python
"""
[L-Service] {Name}Service — {一句话业务描述}

依赖: Python 标准库 + data/ 模块 + core/hotkey_config 等纯模块
禁止: PySide6, QtWidgets, QtGui, QtCore(Signal 除外)
返回: dict / list / bool / str / int(原始类型,绝不返回 Qt 对象)
"""
```

**核心规则**:
- 纯逻辑,不碰 UI
- 不持有 widget 引用(QtCore.Signal 允许,如 QObject 型 Service)
- 单例访问:`cls.instance()`(按需)
- 错误处理:返回 `None`/`False` + 日志,绝不抛异常到 UI
- 涉及网络/IO 必须 try/except,降级到本地缓存
- **网络服务三件套**(价格页/一线战报已落地,新增网络功能必须照做):
  ① 成功拉取后写磁盘缓存(`user_data_dir()` 下) ② 启动/进页面后台预热,
  先渲染缓存秒显 ③ 网络失败降级本地数据源并明确提示状态,绝不白屏卡等

### 6.3 `core/recognizers/` —— L-Recognizer OCR 识别层

```python
"""
[L-Recognizer] {Name} — {识别对象}(OCR 引擎/文本纠正/物品匹配)

依赖: PySide6 视情况(部分模块仅需 numpy/onnxruntime)
职责: 把截图/像素数据/原始文本转换为结构化结果
"""
```

**核心规则**:
- 内部模块可依赖 numpy/onnxruntime/PIL(OCR 引擎需要)
- 输出 dict,绝不返回 Qt 控件
- 匹配器(matcher)输出 `{en_name, zh_name, slug, category, quality}`
- 文本纠正(text_corrector)提供字符串→字符串的纯函数
- 长任务放 QThread/Signal,不要阻塞 UI

### 6.4 `core/widgets/` —— L4/L5 控件层

```python
"""
[L4/L5] Cyber{Name} — {控件描述}

继承: CyberWidgetMixin + {Qt 原生控件}
依赖: core.tokens.manager(只此一个外部)
职责: {绘制什么 + 交互行为}
信号: {发射哪些信号}
"""
```

**核心规则**:
- 必须 `class CyberXxx(CyberWidgetMixin, Qt原生类)`
- `__init__` 显式 `Qxxx.__init__(self, ...)` 不用 super
- `paintEvent`:`QPainter → 自绘 → super()` 固定三步
- 尺寸从 `self.space(...)` 取,不写死数字
- 颜色从 `self.token(...)` 取,不写死颜色
- 沉浸黑模式底色必须调 `core/widgets/immersive.py` 纯函数(禁止手写覆写 RGB/折减 alpha)
- Token 取色用三级兜底(token_color: 指定默认 → alias.bg.raised → 纯黑),防绘制崩溃
- 不调 Service,不发网络请求,不读写 JSON
- 私有属性 `_cyber_xxx` 前缀

### 6.5 `core/pages/` —— L2 页面层

```python
"""
[L2] {Name}Page — {页面名}

依赖: widgets/, sections/, services/
职责: 组装 UI 元素 + 连接信号槽
父类: BasePage (core/pages/base_page.py)
"""
```

**核心规则**:
- 继承 `BasePage`,设 `PAGE_ID` / `PAGE_NAME` / `NAV_ICON`
- 装配 = 创建 Widget + Layout + connect Signal/Slot
- 业务调用通过 `Service.get()` 或回调到上层
- 不写 paintEvent(用 Widget 即可)
- 不硬编码颜色/尺寸(用 token)
- 监听 `on_enter()`/`on_leave()` 生命周期

### 6.6 `core/state/` —— L-State 全局状态层

```python
"""
[L-State] {Name} — {状态职责}

依赖: 纯 Python(可以走 PySide6 Signal,但不持有 widget)
职责: 全局单例状态(EventBus/AppState)的事件收发
"""
```

**核心规则**:
- 全局单例,跨页面共享
- 通过 EventBus 解耦,不直接调用 Page 方法
- 状态变化发信号,订阅方更新 UI

### 6.7 `core/` 根目录文件(混合层)

```python
"""
[L0/L1] {Name} — {职责}

依赖: 视文件而定(app_shell 只用 pages,hotkey_manager 用 win32)
职责: 窗口外壳/全局管理器/跨层桥接
"""
```

**核心规则**:
- 入口/管理器:尽量不包含业务细节,只做编排
- 跨层桥接:可持有 widget 引用,但不实现绘制
- 涉及全局资源(快捷键/主题/数据库连接)单例化

## 7. 绝对禁区(违反任一 = 不合格)

| # | 禁区 | 正确做法 |
|---|---|---|
| 1 | services/ 中 import PySide6 | Service 是纯逻辑 |
| 2 | widgets/ 中读写 JSON | Widget 只绘制和发信号 |
| 3 | pages/ 中 setStyleSheet f-string | Token + Mixin 自绘 |
| 4 | 硬编码颜色/尺寸 | 全部 token/space |
| 5 | 一个方法混 UI 操作和业务 | Widget 发信号,Page 调 Service |
| 6 | 修改旧代码文件 | 旧代码只读 |
| 7 | 根目录创建 .py | 全在 core/ 子目录 |
| 8 | 从 QWidget 零开始自绘 | 继承原生 + Mixin |
| 9 | Widget 直接调 Service 再改其他 Widget | 单向数据流 |
| 10 | 用 PyQt6 / pyqtSignal | 一律 PySide6 / Signal |
| 11 | `__file__` 裸推导资源路径 | core.paths 四件套(见 §9) |
| 12 | 新增网络功能裸拉接口 | 三件套:缓存+预热+降级(见 §6.2) |

## 9. 路径与打包规范(EXE 分发铁律)

### 9.1 路径解析唯一实现(`core/paths.py`)

**禁止任何模块用 `__file__` 裸推导资源位置**(打包后 `__file__` 指向临时解包目录,必然失效)。

| API | 用途 | 打包后实际指向 |
|---|---|---|
| `resource_dir()` | data 类只读资源(presets/worldstate/模板 json) | `_internal/data/` |
| `resource_root()` | assets 类只读资源(fonts/icons) | `_internal/assets/` |
| `user_data_dir()` | 用户可写数据(日志/缓存/运行配置) | exe 旁 `data/`(首启自动建) |
| `ensure_user_file(name)` | 模板复制(warframe.db 等:包内没有→首启从 `_internal/data/` 复制) | exe 旁 `data/xxx` |

### 9.2 打包命令与机制(`build.py`)

```
python build.py --zip     # 一键:PyInstaller → 自检 → 冒烟 → ZIP
python build.py --clean   # 先清 workpath 再构建
```

- **入口固定 `dev.py`**:其 frozen 分支自动跳过提权/装依赖直接 `run_child()`
- hiddenimports 自动扫描 `core/` + `data/` 全部 .py(覆盖 app_shell 字符串懒加载页面)
- datas 白名单显式清单;**排除** `data/all.json`、`dict.en/zh.json`(旧管线遗留)、`wm_items_cache.json`(缓存)
- 必须 `--windowed`(不显示 CMD)、`--noupx`(降杀软误报)、spec 生成到 `build/`
- 排除零引用连带库 torch/torchvision/scipy/pandas/matplotlib(dist 1013MB→494MB,ZIP 176MB)
- 冒烟测试:PIPE 启动 exe 观察 6s,stderr 有 Traceback 即失败(windowed 崩溃会弹对话框撑住进程,单凭存活判断会假阳性)
- 冒烟结束必须 `taskkill /PID <pid> /T /F` 杀整棵进程树 + 按映像名兜底(onedir bootloader 派生子进程,terminate 只杀父进程会残留锁 dist)
- 发行 ZIP 产出后**清理 exe 旁 data/** 保持出厂干净

### 9.3 windowed 模式控制台流兜底(`dev.py` run_child)

`--windowed` 打包后 stdout/stderr 有两种异常形态,入口已统一兜底,**新代码可放心用 `print()` / `sys.stderr.write()`**:

| 形态 | 场景 | 兜底 |
|---|---|---|
| 流为 None | 双击 exe 启动 | 换向 `data/logs/console.log`(UTF-8 行缓冲) |
| 流有效但 GBK 编码 | CMD/管道启动 | `reconfigure(encoding="utf-8", errors="replace")` |

### 9.4 网络环境现实约束

国内访问 `api.warframe.com` / `api.warframe.market` 约 10-45s 甚至超时。
所有在线功能(一线战报/价格页)必须按 §6.2「网络服务三件套」实现;状态提示要区分
「加载中」与「不可用」,降级模式必须说明能力变化(如「仅中文搜索」)。
