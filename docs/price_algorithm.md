# Warframe Market 价格参考算法设计

## 算法流程

```
全部 ingame 卖单
    ↓
[1] 竞争集群检测 → 过滤高价区
    ↓
[2] IQR 异常值过滤 → 过滤极端低价（钓鱼/压价）
    ↓
[3] 统计 API 补充 → 48h 成交量 + 90天加权均价
    ↓
[4] 多源加权参考价 → 市场中位数 + 历史均价 + 最低价
    ↓
[5] 建议买卖价 → 买家 Q1 / 卖家 中位数-1p
    ↓
[6] 置信度评分 → 卖家数 + 价差 + 成交量
```

---

## 步骤详解

### 1. 竞争集群检测 `_find_competitive_cluster()`

从最低价开始扫描，找到第一个显著的价格跳跃（>20% 或 >3p），
跳跃前的价格形成"竞争集群"，跳跃后的价格是"高价区"。

```
卖家价格: [5, 5, 6, 6, 7, 7, 15, 20, 25, 50]
                    ↑ 7→15 跳跃 >20% 且 >3p
竞争集群:   [5, 5, 6, 6, 7, 7]    ← 只算这个区间
高价区丢弃:                 [15, 20, 25, 50]
```

参数:
- `COMPETITIVE_GAP_PCT = 0.20` — 价格跳跃 >20% 视为分界
- `COMPETITIVE_GAP_MIN = 3` — 最小价格跳跃 3p
- `MIN_CLUSTER_SIZE = 3` — 竞争集群最少卖家数

### 2. IQR 异常值过滤 `_remove_iqr_outliers()`

用四分位距 (IQR) 方法过滤异常低价，比固定阈值更稳健。

```
竞争集群: [5, 5, 6, 6, 7, 7]
Q1=5, Q3=7, IQR=2
下界 = 5 - 1.5×2 = 2
结果: 全部保留 (都 ≥2)

如果有 1p 钓鱼单: [1, 5, 5, 6, 6, 7, 7]
Q1=5, Q3=7, IQR=2, 下界=2
结果: [5, 5, 6, 6, 7, 7]  ← 1p 被过滤
```

参数:
- `IQR_MULTIPLIER = 1.5` — 标准 IQR 乘数

### 3. 统计 API 补充

调用 `https://api.warframe.market/v1/items/{slug}/statistics` 获取:
- **48h 成交量**: 衡量市场活跃度
- **90天加权均价**: 长期价格趋势（wa_price）

### 4. 多源加权参考价

```
基础权重:
  reference = 0.50 × 市场中位数 + 0.30 × 90天均价 + 0.20 × 最低价

高成交量 (>100/48h) → 当前市场更可信:
  reference = 0.65 × 市场中位数 + 0.15 × 90天均价 + 0.20 × 最低价

低成交量 (<10/48h) → 历史数据更可信:
  reference = 0.35 × 市场中位数 + 0.50 × 90天均价 + 0.15 × 最低价

无历史数据:
  reference = 0.65 × 市场中位数 + 0.35 × 最低价
```

参数:
- `HIGH_VOLUME_THRESHOLD = 100` — 48h 高成交量阈值
- `LOW_VOLUME_THRESHOLD = 10` — 48h 低成交量阈值

### 5. 建议买卖价

| 价格 | 含义 | 计算 |
|------|------|------|
| **suggested_buy** | 耐心买家入手价 | Q1（25%分位） |
| **suggested_sell** | 快速卖出价 | max(中位数 - 1p, 最低价) |
| **reference_price** | 综合参考价 | 多源加权 |

### 6. 置信度评分

| 因素 | 3分 | 2分 | 1分 | 0分 |
|------|-----|-----|-----|-----|
| 卖家数 | ≥50 | ≥20 | ≥5 | <5 |
| 价差 Q3-Q1 | ≤3p | ≤8p | ≤15p | >15p |
| 48h成交量 | ≥100 | ≥10 | >0 | 0 |

总分 ≥7 → **★ 高置信**，4-6 → **● 中置信**，<4 → **○ 低置信**

## 与当前实现对比

| 维度 | 当前实现（price_service.py） | 文档方案（未实施） |
|------|--------|--------|
| 数据源 | 前 20 个卖单 + 统计 API | 全部 ingame 卖单 + 统计 API |
| 异常值 | 固定阈值 <中位数×0.7（权重降为 0.1） | 竞争集群检测 + IQR 四分位距 |
| 参考价 | 加权均价 sell_weighted | 多源加权（市场+历史+最低） |
| 成交量 | 不参与权重调整 | 动态调整权重 |
| 输出 | sell_weighted + sell_min + sell_median | 参考价 + 建议买卖价 + 置信度 |

> 当前实际运行的算法在 `core/price_service._compute_weighted_price()` 中，采用反压价加权均价策略。
